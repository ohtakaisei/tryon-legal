写真の取扱い（要点）

  • 登録した人物写真・服の画像・生成結果は、お客様の端末内にのみ保存されます。
  • 画像は生成を実行するときだけ、当方のサーバー（Google Cloud Platform）を経由して生成AI（OpenAIのOpenAI API、または予備としてGoogle LLCのGemini API）へ送信されます。OpenAIへの送信は、これに加えて、初めて利用する前にアプリ内で1回表示する確認画面で同意いただいた場合のみ行います（送信先の詳細は第3項）。
  • 送信された画像は、当方のサーバーでメモリ上で処理した後ただちに破棄され、保存されません。データベースにも記録しません。
  • お客様が生成を実行した時点で、この送信に同意いただいたものとして取り扱います（送信なしに生成することはできません）。
  • 当方は、お客様の氏名・メールアドレスを取得しません。
  • 広告配信・行動追跡（トラッキング）は一切行いません。

※ 生成時に画像がGoogleまたはOpenAIへ送信されるため、「画像が端末から出ることはない」という説明はいたしません。実際の動作を正確にお伝えしています。

3. 画像データの取扱い

本アプリの中心となる機能に関わるため、画像の取扱いを個別に説明します。

3-1. 端末内での保存

お客様が登録した人物写真、取り込んだ服の画像、生成された試着画像、および似合う診断レポートの画像は、端末内の本アプリ専用の領域にのみ保存され、当方のサーバーには保存されません。これらは他のアプリからアクセスできず、端末のロック中は読み取れないよう保護されています。また、iCloudバックアップの対象からも除外しています。

3-2. 当方サーバーへの送信と Gemini API

お客様が試着の生成を実行したときに限り、人物写真と服の画像が当方のサーバー（Google Cloud Platform、日本国内リージョン）へ送信されます。バージョン2.1以前の本アプリの標準画質、およびバージョン2.2以降でOpenAI APIが一時的に利用できない場合は、そこからGoogle LLCの生成AIサービス「Gemini API」へ送信されます（それ以外の送信先は第3-2の2項）。生成の実行は、この送信への同意を前提とします。送信を伴わずに生成を行うことはできません。

Google LLCにおける取扱いは次のとおりです。

  • 当方は有償のAPIを利用しており、Googleの規約上、送信された画像がGoogleのAIモデルの学習（訓練）に使用されることはありません。
  • ただし、Googleは不正利用の監視等のため、APIに送信されたデータを同社のポリシーに定める期間、一時的に保持する場合があります。
  • Googleでの処理は日本国外（米国等）のサーバーで行われる場合があります。
  • 詳細はGemini APIの利用規約およびGoogleのプライバシーポリシーをご確認ください。

3-2の2. OpenAI APIへの送信

次の場合に、人物写真と服の画像が当方のサーバーを経由してOpenAIの「OpenAI API」（画像生成モデル GPT Image、および画像を読み取るモデル GPT）へ送信されます。OpenAI APIへの送信は、生成の実行による同意（第3-2項）に加えて、初めて利用する前にアプリ内で1回表示する確認画面で、送信先を確認のうえ同意いただいた場合に限り行います。

  • バージョン2.2以降の本アプリで試着画像を生成するとき（すべての生成）
  • バージョン2.1の本アプリで「高画質」を選択して生成するとき
  • 似合う診断レポートを作成するとき（バージョン2.2以降）。診断のため、登録写真、試着画像、試着した服の画像に加え、ワードローブに保存した服の画像（最大12点）も送信します

バージョン2.2以降でOpenAI APIが一時的に利用できない場合は、予備として第3-2項のGemini APIで生成することがあります。

  • OpenAIの規約上、APIに送信されたデータは、OpenAIのモデルの学習（訓練）に使用されません。
  • ただし、OpenAIは不正利用の監視のため、APIに送信されたデータを最長30日間保持する場合があります。
  • OpenAIでの処理は日本国外（米国等）のサーバーで行われます。
  • 詳細はOpenAIのサービス規約およびOpenAIのプライバシーポリシーをご確認ください。

3-3. 送信された画像の破棄

当方のサーバーは、受け取った画像をメモリ上で処理するのみで、ディスクやストレージサービスに書き込みません。処理の完了後、画像はただちに破棄されます。データベースには、第2項に記載したメタデータのみを記録します。画像データやその一部をログに出力することもありません。

3-4. 削除の方法

端末内の画像は、本アプリ内で写真を撮り直す・削除する操作を行うか、本アプリをアンインストールすることで削除されます。当方のサーバーには画像が保存されていないため、サーバー側での画像の削除依頼は必要ありません。

3-5. 体の情報と服の寸法（サイズ感の判定・任意）

  1. サイズ感の判定（バージョン2.4以降）を使う場合、お客様が入力した身長・体重・普段の服のサイズ・体の寸法は、お使いの端末内（Keychain）にのみ保存し、他の端末へは同期しません。服のサイズ・寸法は、試着結果や手持ちの服とともに端末内に保存します。
  2. これらは、サイズ感の判定を使った生成・似合う診断を実行したときに限り、画像とともに当方のサーバーへ送信されます。当方のサーバーは、サイズ感の判定の計算にのみ使い、保存もログへの出力も行わず、処理の完了後ただちに破棄します。
  3. 画像生成・診断の委託先（第3-2・3-2の2）へは、当方のサーバーで計算した見た目の説明（例:「裾は膝のあたり」）と、身長・服のサイズの表記のみを文章として送信します。体重および体の寸法そのものは委託先へ送信しません。
  4. 入力した体の情報は、本アプリのマイスタジオからいつでも削除できます。アカウントを削除した場合も削除されます。入力しなくても、本サービスの他の機能はすべてご利用いただけます。

3-6. クローゼットの服の詳細と、共有された商品ページの読み取り

  1. クローゼットの服に記録する詳細（名前・ブランド・価格・購入店・商品ページのURL・サイズ・色・素材・季節・購入日・メモ・状態。バージョン2.4以降。入力は任意です）は、お使いの端末内にのみ保存し、当方のサーバーへは送信しません。
  2. 通販サイトなどのページを本アプリへ共有したとき、そのページに公開されている商品の情報（品名・ブランド・価格・通貨・サイト名・色・素材）を、お使いの端末の中で読み取り、詳細に自動で入れます。読み取れなかった項目を補うため、本アプリがお使いの端末から共有されたページへ直接アクセスすることがあります。ページの内容や URL を当方のサーバーへ送信することはありません。
  3. 共有した服をクローゼットに保存しないことも選べます。保存しない場合、その服の画像と詳細は試着に使ったあと端末から削除します。保存した服と詳細は、クローゼットからいつでも削除できます。

4. 利用目的

取得した情報は、次の目的でのみ利用します。

  1. 試着画像の生成という本サービスの提供のため
  2. クレジット残数の管理、および二重課金・二重引き落としの防止のため
  3. 購入内容の確認とクレジットの付与のため
  4. 不正利用の防止およびサービスの安定運用のため
  5. お問い合わせへの対応のため

当方は、取得した情報を広告配信・行動ターゲティング・プロファイリングに利用しません。また、ユーザーを他社サービスをまたいで追跡することもありません。

6. 保存期間

  • 画像データ: サーバーには保存しません（第3項）。端末内のデータは、お客様が削除するまで保持されます。
  • 生成リクエストの記録: 記録日から30日が経過した時点で自動的に削除されます。
  • アカウント情報・クレジット情報・購入情報: アカウントが有効な間、および法令上必要な期間保持します。削除のご依頼があった場合は、第8項の手続きにより削除します。

7. 安全管理措置

  • 通信はすべてHTTPSにより暗号化しています。
  • 生成AIのAPIキーは、アプリ本体には含めず、サーバー側の秘密情報として管理しています。
  • データベースへの読み書きは、当方のサーバーからのみ行えるよう制限しています。
  • 端末内の画像には、OSのデータ保護機能を適用し、端末のロック中は読み取れないようにしています。
  • 画像データ・認証トークンをログに出力しない運用としています。
