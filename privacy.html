写真の取扱い（要点）

  • 登録した人物写真・服の画像・生成結果は、お客様の端末内にのみ保存されます。
  • 画像は生成を実行するときだけ、当方のサーバー（Google Cloud Platform）を経由して生成AI（OpenAIのOpenAI API、または予備としてGoogle LLCのGemini API）へ送信されます。OpenAIへの送信は、これに加えて、初めて利用する前にアプリ内で1回表示する確認画面で同意いただいた場合のみ行います（送信先の詳細は第3項）。
  • 送信された画像は、当方のサーバーでメモリ上で処理した後ただちに破棄され、保存されません。データベースにも記録しません。
  • お客様が生成を実行した時点で、この送信に同意いただいたものとして取り扱います（送信なしに生成することはできません）。
  • 当方は、お客様の氏名・メールアドレスを取得しません。Android 版で任意に「Google でサインイン」をした場合も、Google から受け取る情報のうちアカウントの識別子だけを使い、氏名・メールアドレスは使わず、保存もしません（第2項）。
  • 広告配信・行動追跡（トラッキング）は一切行いません。
  • Android 版では、人物写真に写っている人や服の部位を端末の中で判定するために Google の部品（ML Kit・MediaPipe）を使います。このとき画像は端末の外へ送りませんが、部品の性能の指標が Google へ送られることがあります（第3-8）。

※ 生成時に画像がGoogleまたはOpenAIへ送信されるため、「画像が端末から出ることはない」という説明はいたしません。実際の動作を正確にお伝えしています。

TryOn運営チーム（以下「当方」といいます）は、アプリケーション「TryOn」（App Store で配信する iPhone 向けのもの（以下「iOS 版」といいます）と、Google Play で配信する Android 向けのもの（以下「Android 版」といいます）。以下あわせて「本アプリ」といいます）における個人情報および利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

本ポリシーは、とくに「iOS 版」「Android 版」と断りのない限り、両方に適用します。また、バージョンを示した記述（「バージョン2.2以降」など）は iOS 版のバージョンを指します。Android 版はバージョン2.4.0から提供しており、「バージョン2.4以降」の記述が当てはまります。

3. 画像データの取扱い

本アプリの中心となる機能に関わるため、画像の取扱いを個別に説明します。

3-1. 端末内での保存

お客様が登録した人物写真、取り込んだ服の画像、生成された試着画像、および似合う診断レポートの画像は、端末内の本アプリ専用の領域にのみ保存され、当方のサーバーには保存されません。これらは他のアプリからアクセスできません。

  • iOS 版: 端末のロック中は読み取れないよう保護しています。また、iCloudバックアップの対象からも除外しています。
  • Android 版: Android のクラウドへのバックアップと、端末間のデータの移行（機種変更の際のコピーなど）の対象から除外しています。

3-2. 当方サーバーへの送信と Gemini API

お客様が試着の生成を実行したときに限り、人物写真と服の画像が当方のサーバー（Google Cloud Platform、日本国内リージョン）へ送信されます。バージョン2.1以前の本アプリの標準画質、およびバージョン2.2以降でOpenAI APIが一時的に利用できない場合は、そこからGoogle LLCの生成AIサービス「Gemini API」へ送信されます（それ以外の送信先は第3-2の2項）。生成の実行は、この送信への同意を前提とします。送信を伴わずに生成を行うことはできません。

Google LLCにおける取扱いは次のとおりです。

  • 当方は有償のAPIを利用しており、Googleの規約上、送信された画像がGoogleのAIモデルの学習（訓練）に使用されることはありません。
  • ただし、Googleは不正利用の監視等のため、APIに送信されたデータを同社のポリシーに定める期間、一時的に保持する場合があります。
  • Googleでの処理は日本国外（米国等）のサーバーで行われる場合があります。
  • 詳細はGemini APIの利用規約およびGoogleのプライバシーポリシーをご確認ください。

3-2の2. OpenAI APIへの送信

次の場合に、人物写真と服の画像が当方のサーバーを経由してOpenAIの「OpenAI API」（画像生成モデル GPT Image、および画像を読み取るモデル GPT）へ送信されます。OpenAI APIへの送信は、生成の実行による同意（第3-2項）に加えて、初めて利用する前にアプリ内で1回表示する確認画面で、送信先を確認のうえ同意いただいた場合に限り行います。

  • バージョン2.2以降の本アプリで試着画像を生成するとき（すべての生成）
  • バージョン2.1の本アプリで「高画質」を選択して生成するとき
  • 似合う診断レポートを作成するとき（バージョン2.2以降）。診断のため、登録写真、試着画像、試着した服の画像に加え、ワードローブに保存した服の画像（最大12点）も送信します

バージョン2.2以降でOpenAI APIが一時的に利用できない場合は、予備として第3-2項のGemini APIで生成することがあります。

  • OpenAIの規約上、APIに送信されたデータは、OpenAIのモデルの学習（訓練）に使用されません。
  • ただし、OpenAIは不正利用の監視のため、APIに送信されたデータを最長30日間保持する場合があります。
  • OpenAIでの処理は日本国外（米国等）のサーバーで行われます。
  • 詳細はOpenAIのサービス規約およびOpenAIのプライバシーポリシーをご確認ください。

3-3. 送信された画像の破棄

当方のサーバーは、受け取った画像をメモリ上で処理するのみで、ディスクやストレージサービスに書き込みません。処理の完了後、画像はただちに破棄されます。データベースには、第2項に記載したメタデータのみを記録します。画像データやその一部をログに出力することもありません。

3-4. 削除の方法

端末内の画像は、本アプリ内で写真を撮り直す・削除する操作を行うか、本アプリをアンインストールすることで削除されます。当方のサーバーには画像が保存されていないため、サーバー側での画像の削除依頼は必要ありません。

3-5. 体の情報と服の寸法（サイズ感の判定・任意）

  1. サイズ感の判定（バージョン2.4以降）を使う場合、お客様が入力した身長・体重・普段の服のサイズ・体の寸法は、お使いの端末内（iOS 版は Keychain、Android 版は Android Keystore の鍵で暗号化した本アプリ専用の領域）にのみ保存し、他の端末へは同期しません。服のサイズ・寸法は、試着結果や手持ちの服とともに端末内に保存します。
  2. これらは、サイズ感の判定を使った生成・似合う診断を実行したときに限り、画像とともに当方のサーバーへ送信されます。当方のサーバーは、サイズ感の判定の計算にのみ使い、保存もログへの出力も行わず、処理の完了後ただちに破棄します。
  3. 画像生成・診断の委託先（第3-2・3-2の2）へは、当方のサーバーで計算した見た目の説明（例:「裾は膝のあたり」）と、身長・服のサイズの表記のみを文章として送信します。体重および体の寸法そのものは委託先へ送信しません。
  4. 入力した体の情報は、本アプリのマイスタジオからいつでも削除できます。アカウントを削除した場合も削除されます。入力しなくても、本サービスの他の機能はすべてご利用いただけます。

3-6. クローゼットの服の詳細と、共有された商品ページの読み取り

  1. クローゼットの服に記録する詳細（名前・ブランド・価格・購入店・商品ページのURL・サイズ・色・素材・季節・購入日・メモ・状態。バージョン2.4以降。入力は任意です）は、お使いの端末内にのみ保存し、当方のサーバーへは送信しません。
  2. 通販サイトなどのページを本アプリへ共有したとき、そのページに公開されている商品の情報（品名・ブランド・価格・通貨・サイト名・色・素材）を、お使いの端末の中で読み取り、詳細に自動で入れます。読み取れなかった項目を補うため、本アプリがお使いの端末から共有されたページへ直接アクセスすることがあります。ページの内容や URL を当方のサーバーへ送信することはありません。
  3. 共有した服をクローゼットに保存しないことも選べます。保存しない場合、その服の画像と詳細は試着に使ったあと端末から削除します。保存した服と詳細は、クローゼットからいつでも削除できます。

3-7. 似合うプロフィールの診断（パーソナルカラー・骨格・体の寸法・任意）

  1. パーソナルカラー・骨格・体の寸法の診断（バージョン2.4以降。各1クレジット。それぞれ初回は無料）を実行したときに限り、お客様が選んだ写真と、骨格の質問への回答（選択肢のみ）・身長を、当方のサーバー経由で診断の委託先（OpenAI。第3-2の2）へ送信します。当方のサーバーは、写真・回答・結果を保存もログへの出力も行わず、診断の完了後ただちに破棄します。
  2. 診断の結果（似合う色・骨格のタイプ・推定した体の寸法など）は、お使いの端末内（第3-5と同じく、iOS 版は Keychain、Android 版は Android Keystore の鍵で暗号化した領域）にのみ保存し、他の端末へは同期しません。どの写真で診断したかを結果とあわせて表示するため、診断に使った写真の縮小したコピーも端末内（第3-1と同じ領域）にのみ保存します。診断をやり直すか結果を削除すると、このコピーも削除します。
  3. 似合う診断を実行するとき、保存した結果の要約（パーソナルカラーのタイプと似合う色・苦手な色の名前、骨格のタイプと似合う形・避けたい形、体型の名称）を、採点と講評のために当方のサーバー経由で委託先へ文章として送信します。推定した体の寸法の数値は送信しません。
  4. 推定した体の寸法は、お客様が選んだ場合に限り、サイズ感の判定の体の情報（第3-5）へ取り込みます。入力済みの値は、置き換えを選ばない限り変わりません。
  5. 結果は本アプリの「似合うプロフィール」からいつでも削除できます。アカウントを削除した場合も削除されます。診断しなくても、本サービスの他の機能はすべてご利用いただけます。
  6. 診断は AI による推定で、専門家による診断の代わりとなるものではありません。

3-8. 端末の中での画像の判定（Android 版）

  1. Android 版は、Google LLC が提供する、端末の中で動く部品を使います。共有された服の画像から部位（トップス・靴など）を推定するために ML Kit を、登録する人物写真に人が1人だけ写っているかなどを確かめるために MediaPipe を使います。
  2. これらの判定はお使いの端末の中だけで行い、判定のために画像を端末の外へ送ることはありません。（生成のときの画像の送信は、第3-2・3-2の2のとおりです。）
  3. ただし、これらの部品は、部品の性能と利用状況を測るための指標（処理にかかった時間、端末の機種、OSのバージョン、本アプリのバージョン、エラーの種類、インストールごとの識別子など）を Google へ送ることがあります。写真そのものは含みません。当方はこれらの指標を受け取りません。Google における取扱いはML Kit のデータの開示およびGoogleのプライバシーポリシーによります。

3-9. 識別用の符号の保存（Google Block Store）

  1. サインインせずに利用するための識別用の符号（第2項）は、本アプリが端末内で作成し、端末内にのみ保存します。iOS 版では端末の Keychain に保存し、他の端末へは同期しません。Android 版では Android Keystore の鍵で暗号化して本アプリ専用の領域に保存します。
  2. Android 版では、本アプリを削除してから入れ直しても同じアカウントで続けられるよう、この符号の控えを Google Play 開発者サービスの Block Store に置きます。控えはその端末の中だけに保存し、クラウドへのバックアップには送りません。Google Play 開発者サービスが使えない端末では控えを置けず、入れ直すと新しいアカウントになります。
  3. アカウントを削除すると、端末内の符号と Block Store の控えの両方を削除します。

3-10. シェア用の画像

3-12. 似合う髪型診断（任意）

  1. 似合う髪型診断（バージョン2.4以降。1回3クレジット）では、お客様が選んだ顔の写真から、お使いの端末の中で顔の目印の位置（眉・目・鼻・口・輪郭）を検出し、顔の縦横の比率・あごの幅の比率などの数字を計算します（iOS 版は Apple の Vision、Android 版は Google の ML Kit を使い、端末の外へは送りません）。目印の位置そのものは保存も送信もしません。また、顔の情報を個人の識別・認証・広告・分析その他の目的に使うことはありません。
  2. 診断を実行したときに限り、顔の写真（任意で前髪を上げた写真をもう1枚）、計算した比率の数字、質問への回答（選択肢のみ）、似合うプロフィールの結果の要約（パーソナルカラーと骨格のタイプなど。第3-7）を、当方のサーバー経由で委託先（OpenAI。第3-2の2）へ送信し、似合う髪型の診断と、顔の写真をもとにした3つの髪型の画像の作成に使います。当方のサーバーは、写真・数字・回答・結果を保存もログへの出力も行わず、診断の完了後ただちに破棄します。
  3. 診断の結果と画像は、お使いの端末内（第3-1と同じ領域）にのみ保存し、他の端末へは同期せず、バックアップにも含めません。本アプリからいつでも削除でき、アカウントを削除した場合も削除されます。
  4. 似合う髪型診断の結果は、似合う診断（服）や似合うプロフィールには使いません。
  5. 診断は AI による推定で、専門家による診断の代わりとなるものではありません。仕上がりは髪質や美容師の技術によって変わります。

3-13. 写真で楽しむ診断（任意）

  1. 写真で楽しむ診断（バージョン2.4以降。1回2クレジット、運命の相手は3クレジット）を実行したときに限り、お客様が選んだ顔の写真（診断によっては全身の写真も）、質問への回答（選択肢のみ）、端末の地域の設定（国・地域の2文字のコード）を、当方のサーバー経由で委託先（OpenAI。第3-2の2）へ送信し、診断の文章と結果の画像の作成に使います。将来の子ども顔・結婚式では、お客様自身の運命の相手の診断で作られた相手の画像もあわせて送信します。当方のサーバーは、写真・回答・結果を保存もログへの出力も行わず、診断の完了後ただちに破棄します。
  2. 顔の写真から人種・民族・年齢などを推定することはありません。運命の相手の国は端末の地域の設定から、年代は質問への回答から決めます。
  3. 結果に登場するお客様以外の人物（相手・子どもなど）は、AI が作った架空の人物です。実在の人物の写真を相手として使うことはできません。
  4. 診断の結果と画像は、お使いの端末内（第3-1と同じ領域）にのみ保存し、他の端末へは同期せず、バックアップにも含めません。本アプリからいつでも削除でき、アカウントを削除した場合も削除されます。
  5. 写真で楽しむ診断の結果は、似合う診断（服）や似合うプロフィールには使いません。診断は娯楽を目的としたもので、内容を保証するものではありません。
