はじめに（要点）

  • 登録できる全身写真はご本人のものだけです。他人の写真は登録できません。
  • 18歳未満の方が写った画像は登録・使用できません。
  • 生成された画像を、他人を傷つける目的で使わないでください。
  • 写真はお客様の端末内に保存されます。生成時のみ画像を送信し、当方のサーバーには保存しません（詳細はプライバシーポリシー）。

以下は正式な規約本文です。上の4点をお守りいただければ、通常のご利用で問題になることはありません。

第1条（適用）

  1. 本利用規約（以下「本規約」といいます）は、TryOn運営チーム（以下「当方」といいます）が提供するiOS向けアプリケーション「TryOn」（以下「本アプリ」といいます）およびこれに付随するサービス（以下あわせて「本サービス」といいます）の利用条件を定めるものです。
  2. お客様（以下「ユーザー」といいます）は、本サービスを利用することにより、本規約に同意したものとみなされます。
  3. 当方が本アプリ内またはウェブサイト上で掲示する個別の注意事項・ガイドラインは、本規約の一部を構成します。

第2条（定義）

登録写真 ユーザーが本アプリのカメラで撮影し、本アプリ内に登録した本人の人物写真（正面全身・上半身・別の角度）をいいます。
服の画像 ユーザーが試着の対象として本アプリに取り込んだ衣服等の画像をいいます。
生成物 登録写真と服の画像をもとに、生成AIによって作成された画像をいいます。
クレジット 生成物の作成に必要な、本サービス内でのみ利用できる単位をいいます。

第3条（アカウント）

  1. 本サービスは、アカウントの登録をせずに利用できます（バージョン2.3以降の本アプリ）。この場合、本アプリが端末内に作成する識別用の符号（端末の外へは同期しません）により、ユーザーを識別します。
  2. ユーザーは任意で、Appleが提供する「Sign in with Apple」によりサインインできます。サインインすると、その端末でのクレジットおよびプランをAppleのアカウントに引き継ぎ、ほかの端末でも利用できます。当方はAppleから提供される識別子のみを取得し、氏名およびメールアドレスは取得しません。バージョン2.2以前の本アプリでは、サインインが必要です。
  3. サインインせずに利用している場合、端末の初期化や機種変更により、残りのクレジットを引き継げないことがあります。有料プランは、App Storeの「購入を復元」により、別の端末でも引き続き利用できます（このとき、プランおよび当月の残りのクレジットは、復元を行った端末で利用しているアカウントへ移ります）。
  4. ユーザーは、自己の責任においてApple IDおよび端末を管理するものとします。

第4条（クレジットおよび料金）

4-1. クレジットの付与

  2. 有料プランにご加入いただくと、プランに応じたクレジットを毎月付与します。
  3. 追加クレジットパックは、有料プランにご加入中のユーザーのみ購入できます。
  4. 1回分（4クレジット。試着1回と似合う診断レポート1回に相当します）は、有料プランへの加入の有無にかかわらず購入できます（バージョン2.3以降の本アプリ）。

4-2. クレジットの消費

  1. 生成1枚あたりの消費クレジットは1です。ただし、バージョン2.1の本アプリで「高画質」を選択した場合は2です（バージョン2.2以降は画質の選択はなく、すべて1枚1クレジットです）。
  2. コーデ（上着・トップス・ボトムス・帽子・メガネ・手袋・靴・アクセサリー）は、組み合わせた服が4点までなら1枚1クレジット、5点以上なら1枚2クレジットです（バージョン2.2以降）。バージョン2.1以前の本アプリでは、点数にかかわらず前号のとおりです。消費数は実行前に必ず画面に表示します。
  3. 比較モードで同じ部位の候補を2〜3点比べる場合は、生成される枚数分のクレジット（2〜3。バージョン2.1の高画質では4〜6）を消費します。消費数は実行前に必ず画面に表示します。
  4. 仕上がりの種類（全身1枚／複数アングル1枚）による消費クレジットの差はありません。
  5. 同じ条件での作り直しは、1つの生成結果につき1回まで、1クレジットで行えます。
  6. 似合う診断レポート（試着結果をもとに、スコア・講評・合わせる服の提案を1枚の画像にまとめる機能。バージョン2.2以降の本アプリで利用できます）は、1回につき3クレジットを消費します。作成済みのレポートを見直すときは消費しません。

4-3. クレジットの繰り越しと失効

  1. 毎月付与されるプランのクレジットは、翌月に繰り越されません。
  2. 追加パックで購入したクレジットは繰り越されますが、有料プランの期間が更新されずに終了した時点で失効します。解約の手続きをした時点では失効せず、第5条第4項のとおり現在の期間の終了までご利用いただけます。
  3. 1回分で購入したクレジットは繰り越され、有料プランの期間終了による失効の対象外です。
  4. クレジットは換金・払い戻し・ユーザー間の譲渡ができません。

4-4. 生成に失敗した場合

通信エラー、生成AIによる出力の拒否等により画像が得られなかった場合、消費したクレジットは全額を自動的に返還します。ユーザーによる申請は不要です。

4-5. プロプラン

  1. プロプラン（バージョン2.3以降の本アプリ）に加入している期間は、試着（コーデ・比較を含みます）および似合う診断レポートの作成にクレジットを消費しません。
  2. 生成できる量は1日（日本時間の0時から24時まで）あたり100枚までです。似合う診断レポートは1回を3枚分、比較は生成される枚数分、5点以上の服を組み合わせたコーデは1枚を2枚分として数えます。上限に達した場合は、翌日の0時（日本時間）から再びご利用いただけます。生成に失敗した分は数えません。
  3. 不正な利用や過度な負荷を防ぐため、同時に実行できる生成は1件までとします。また、本サービス全体の混雑等により、一時的に生成を制限することがあります。
  4. 本アプリに表示する1枚あたりの金額は、30日間毎日100枚を生成した場合の目安です。
  5. 当方は、本プランの運営および上限の見直しのため、利用者ごとの利用回数を、利用者を直接特定できない形で集計します。

第5条（サブスクリプションの決済・更新・解約）

  1. 本サービスの有料プランおよび追加パックの決済は、すべてApple App Storeを通じて行われます。
  2. サブスクリプションは、期間終了の24時間前までに解約されない限り、同一の内容・価格で自動更新されます。更新料金は、期間終了前の24時間以内にApple IDに請求されます。
  3. 解約は、iPhoneの「設定」＞ご自身のApple ID＞「サブスクリプション」からいつでも行えます。当方では解約手続きを代行できません。
  4. 解約は次回更新日から有効となり、日割りでの返金は行われません。現在の期間中は引き続きご利用いただけます。
  5. 購入後の返金については、Appleの定める規定および手続きに従います。
  6. 料金を変更する場合は、事前に本アプリ内またはウェブサイト上で告知します。

第6条（登録写真に関する遵守事項）

本条は本サービスの根幹に関わる重要な条項です。違反が確認された場合、当方は事前の通知なく本サービスの提供を停止することがあります。

  1. ユーザーは、ユーザー自身が写った写真のみを登録写真として登録できます。ユーザー以外の人物が写った写真を登録してはなりません。
  2. ユーザーは、18歳未満の人物が写った画像を、登録写真・服の画像を問わず本サービスに使用してはなりません。
  3. 登録写真は、本アプリのカメラで撮影したものに限られます。本アプリは、フォトライブラリから人物写真を登録する機能を提供していません。
  4. 服の画像については、ユーザーが正当に利用できる画像（自ら撮影した画像、または利用が許諾されている画像等）をご利用ください。店舗内での撮影は、店舗の許可を得たうえで行ってください。

第6条の2（画像の送信および生成AIの利用への同意）

  1. 試着画像の生成および似合う診断レポートの作成には、登録写真および服の画像等を、当方のサーバー（Google Cloud Platform、日本国内リージョン）を経由して、次の生成AIサービスへ送信することが必要です。ユーザーは、生成を実行することにより、この送信に同意したものとみなします。ただし、OpenAI APIへの送信は、これに加えて、初めて利用する前にアプリ内で1回表示する確認画面で、送信先を確認のうえ同意いただいた場合に限り行います。
    • OpenAIの「OpenAI API」: バージョン2.2以降のすべての生成と似合う診断レポート（似合う診断レポートはバージョン2.2以降の機能です）、およびバージョン2.1で高画質を選択した場合。似合う診断レポートでは、診断のために、登録写真、試着画像、試着した服の画像に加え、ワードローブに保存した服の画像（最大12点）も送信します。
    • Google LLCの「Gemini API」: バージョン2.1以前の標準画質、およびバージョン2.2以降でOpenAI APIが一時的に利用できない場合の予備。
  2. 当方のサーバーは送信された画像を保存せず、処理後ただちに破棄します。Google LLCおよびOpenAIにおける取扱い（不正利用監視のための一時保持、日本国外での処理を含みます）は、各社の規約およびプライバシーポリシーによります。詳細は当方のプライバシーポリシー第3項をご確認ください。
  3. 前項の送信に同意いただけない場合、生成機能はご利用いただけません（登録写真の閲覧・削除等、送信を伴わない機能はご利用いただけます）。

第7条（生成物の取扱い）

  1. 生成物（似合う診断レポートの画像を含みます）および登録写真は、ユーザーの端末内にのみ保存され、当方のサーバーには保存されません。当方は生成物を保存・閲覧しません。
  2. 当方は、生成物に関する権利をユーザーに対して主張しません。ただし、生成物のもととなった服のデザイン等について第三者が有する権利は影響を受けません。
  3. ユーザーは、生成物を第三者の名誉、信用、プライバシーその他の権利を害する目的で使用してはなりません。
  4. 生成物は生成AIによる推定であり、実際の着用時の見え方、サイズ感、色味、素材感を保証するものではありません。購入の判断は、生成物のみに依拠せず、ユーザー自身の責任で行ってください。
  5. 生成物では、登録写真の顔立ち・体型・背景が多少変化します。生成AIは人物を描き起こすため、元の写真と完全に同一の外観にはなりません。
